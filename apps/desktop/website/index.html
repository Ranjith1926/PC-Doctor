Install in 3 steps

It takes about a minute. You do not need administrator rights.

  1. Download the Installer or the Portable fileUse the buttons at the top of this page. The Installer adds a Start menu entry. The Portable file runs on its own.
  2. Run it, and allow Windows to continueThis build is not code-signed yet, so Windows may show "Windows protected your PC". Choose More info, then Run anyway. Only do this for a file you downloaded from this page.
  3. Open PC Doctor and run a Quick ScanYou get your health score in about 15 seconds. Nothing on your PC is changed until you review and approve it.

Questions

Is PC Doctor safe to use?

It never deletes anything without showing you a preview and asking you to confirm. It will not touch Documents, Desktop, Downloads, Pictures, Videos, Music, OneDrive or project folders.

Why does Windows warn me?

The file is not signed with a paid code-signing certificate yet, so Windows cannot recognise the publisher. Check the SHA-256 value above to be sure your file is exactly the one published here.

Does it send my data anywhere?

No. PC Doctor has no account, no telemetry and blocks itself from contacting the internet. Scan history is stored on your PC only.

How do I remove it?

If you used the Installer, uninstall it from Windows Settings, Apps. If you used the Portable file, delete it. To remove saved history too, delete the folder %APPDATA%\pc-doctor-desktop.
